# 《破映》GameEntry 分层素材 v1

## 当前状态

本目录只包含已经生成并完成透明背景处理的美术素材。尚未替换旧背景，也尚未修改或组装 `GameEntry` 场景。

## 母版生成要求

- 16:9 横版入口画面，无文字、菜单、标签和水印。
- 中央主镜为主要视觉焦点，镜外保留一个白色无面主角。
- 左上为冷蓝遗迹碎片，右上为丛林遗迹碎片，右下为紫色遗迹碎片。
- 深蓝星空与低雾背景，保留顶部标题区和右侧单一入口按钮区。
- 使用现有 GameEntry 的克制蓝黑色调，不做复杂倒影表演。

## 文件用途

| 文件 | 用途 |

| `GameEntry_MasterPreview_v1.png` | 构图与最终观感参考，不直接作为动态背景使用 |

| `GameEntry_MirrorPortal_v1.png` | 主镜独立层，用于呼吸光、镜面流动和进入过场 |
| `GameEntry_Fragment_BlueRuins_v1.png` | 蓝色遗迹独立层，用于漂浮与边缘扫光 |
| `GameEntry_Fragment_Jungle_v1.png` | 丛林遗迹独立层，用于漂浮、落叶与水流效果 |
| `GameEntry_Fragment_VioletRuins_v1.png` | 紫色遗迹独立层，用于漂浮与雾气效果 |
| `GameEntry_Protagonist_v1.png` | 镜外主角独立层，用于轻微待机与入镜移动 |
| `GameEntry_FloatingShardsSheet_v1.png` | 十二枚浮空碎屑，后续切片后随机漂浮 |

## 预定界面文字

- 标题：`破映`
- 唯一入口：`踏入镜隙`
- 不使用副标题。
