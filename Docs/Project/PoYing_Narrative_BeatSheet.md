## 三、编辑方法

1. 在 Unity 中打开需要修改的关卡。
2. 选择 `MirrorTrial → 剧情 → 打开关卡剧情编辑器`。
3. 左侧选择剧情段落。
4. 在“何时播放”中修改触发方式、延迟和是否只播放一次。
5. 在“演出步骤”中修改文字、顺序、教学目标或停留时间。
6. 进入运行模式后，使用“播放当前段落”单独预览。
7. 点击“检查”，确认触发对象、镜头和字体没有遗漏。
8. 保存场景。

剧情编辑器中的“内心独白”不会显示说话人。操作教学属于系统提示，可以直接写“移动”“跳跃”“攻击”“闪避”。

批量写入初稿的临时入口已经移除。后续修改只通过关卡剧情编辑器进行，避免误覆盖已经润色的内容。

## 四、打磨时优先检查

- 这句话是否真的需要出现。
- 主角此刻是否已经知道这件事。
- 能否通过镜头、Boss 动作或角色变化表达，而不使用文字。
- 是否像一个人当下会想到的话。
- 删除这句话后，玩家是否仍能理解目标。

如果删除后不影响理解，优先删除。
