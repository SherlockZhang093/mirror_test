# 《镜中试炼》整体美术风格策划

## 方案一：裂光镜面

## 一、美术定位

《镜中试炼》采用**极简冷光像素风**，以低细节角色、深色场景和高识别度镜面特效构成整体视觉。

游戏不追求复杂写实的场景资产，也不采用厚重华丽的哥特魔幻风格，而是通过简洁轮廓、有限配色、大片留白以及镜面裂纹产生的冷光，营造一种安静、压抑、神秘且具有心理对抗感的世界。

角色、场景和敌人的基础造型保持克制，主要视觉资源集中在以下关键节点：

* 镜中倒影异常；
* 玩家主动击碎镜面；
* 镜像Boss现身；
* 镜面裂纹不断扩散；
* Boss破碎并被玩家吸收；
* 镜像世界与现实世界切换。

整体视觉原则可以概括为：

> **基础画面极简，关键时刻爆发；现实世界稳定，镜像世界失真；玩家纯净明亮，镜像自我黑暗锋利。**

这一方向能够延续当前“镜子连接关卡、Boss与能力夺取”的核心结构，同时避免镜子只被做成普通传送门。

---

## 二、核心视觉关键词

| 维度   | 关键词            |
| ---- | -------------- |
| 整体风格 | 极简、像素、冷峻、克制    |
| 世界氛围 | 孤独、安静、压迫、失真    |
| 镜子表现 | 裂纹、反射错位、冷光、破碎  |
| 战斗表现 | 清晰、锋利、短促、强反馈   |
| 角色关系 | 白色玩家、黑色镜像、同形异质 |
| 镜中世界 | 对称、漂浮、断裂、反常空间  |

游戏不依靠大量装饰讲述世界观，而是依靠“形状、颜色和运动规律”建立视觉识别。

---

# 三、整体画面结构

游戏画面采用明显的三层结构。

## 1. 前景交互层

包括玩家、敌人、平台、镜子、机关和战斗特效，是画面中对比度最高、轮廓最清晰的部分。

玩家需要能够快速识别：

* 哪里可以站立；
* 什么对象可以攻击；
* 敌人的攻击方向；
* 镜子当前处于什么状态。

因此前景不使用过多纹理和复杂装饰，所有可交互对象都应具有明确轮廓。

## 2. 中景环境层

中景用于建立现实世界的空间感，例如：

* 破损墙面；
* 柱体和门框；
* 悬挂结构；
* 远处平台剪影；
* 少量与镜子有关的裂痕和反光。

中景颜色比前景更暗，避免干扰战斗。

## 3. 远景气氛层

远景主要承担氛围，不承担玩法信息。

可以使用：

* 大面积深色渐变；
* 模糊建筑剪影；
* 缓慢移动的雾；
* 少量漂浮颗粒；
* 极弱的垂直光带。

远景应尽量留白，让极简角色和镜子成为绝对视觉中心。

---

# 四、角色美术风格

## 1. 玩家角色

玩家保持当前的极简人形设计，以浅灰白色块构成人体轮廓，不强调具体五官、服饰纹理和复杂装备。

玩家的视觉特征为：

* 头部和躯干采用简洁几何形；
* 四肢保持清晰，方便阅读动作；
* 主体颜色接近白色；
* 阴影只使用一至两个灰阶；
* 可以保留一块深色披肩、围巾或残片作为动作拖尾；
* 不绘制复杂面部表情。

角色高度建议控制在约 **48—64像素**的制作规格中，根据实际摄像机画面调整。重点是让移动、攻击和受击动作容易辨认，而不是展示角色细节。

### 玩家颜色建议

| 部位    | 建议颜色      |
| ----- | --------- |
| 主体高光  | `#EEF3F6` |
| 主体阴影  | `#B8C1CA` |
| 深色配件  | `#343B48` |
| 能力激活光 | `#8EDFFF` |

玩家的白色代表“尚未被能力填满的空白自我”，也方便与深色镜像形成对比。

---

## 2. 镜像Boss

镜像Boss与玩家保持相同基础轮廓和动作结构，但通过色彩、姿态和特效形成差异。

主要表现方式：

* 主体由深灰或黑色构成；
* 面部没有五官，只保留一到两个发光点；
* 身体边缘出现冷蓝色裂光；
* 动作幅度更大、姿态更具有攻击性；
* 对应能力集中显示在武器、手臂或身体裂缝处；
* 站立时也可以存在轻微残影或错位。

### 镜像Boss颜色建议

| 部位    | 建议颜色      |
| ----- | --------- |
| 主体暗色  | `#111722` |
| 次级轮廓  | `#263247` |
| 裂光    | `#65CCFF` |
| 强调光   | `#D6F5FF` |
| 特殊能力光 | `#887BFF` |

玩家与Boss应当一眼看出“同源”，但不能只是简单换色。Boss应像玩家轮廓被镜面拉伸、切割和重组后的版本。

---

# 五、核心镜子设计

## 1. 基础造型

镜子采用竖直长方形或轻微圆角的修长结构，高度约为玩家的 **2.5—3倍**，宽度约为玩家的 **1.5倍**。

镜框不使用复杂雕花和尖刺，而采用：

* 纤细黑色金属框；
* 简单分段结构；
* 局部缺口；
* 少量镜面碎片附着；
* 底部直接接触地面。

镜框的功能是强化镜子轮廓，而不是表现其华贵。玩家第一眼应该先看到镜面里的异常倒影，而不是镜框装饰。

---

## 2. 初始状态

镜子初次出现时总体完整，镜面呈低饱和灰蓝色。

初始视觉包括：

* 少量不发光的细裂纹；
* 模糊但可识别的玩家倒影；
* 轻微纵向反光；
* 镜面内部比现实背景略暗；
* 偶尔出现一帧错位或图像抖动。

此时镜子处于安静状态，不使用大量粒子和高亮效果。

---

## 3. 倒影异常

当玩家靠近镜子时，倒影开始出现异常。

异常表现可以按强度逐渐增加：

1. 倒影比玩家慢半拍；
2. 玩家停止后，倒影仍然移动一步；
3. 倒影头部转向玩家；
4. 倒影姿态逐渐变成对应Boss姿态；
5. 倒影短暂展示玩家尚未拥有的能力。

这一阶段不要立刻让整面镜子发光。视觉重点应集中在镜中人本身，让玩家产生“它已经不再是普通倒影”的感觉。

---

## 4. 普通攻击破镜

玩家可以使用任意普通攻击击打镜面。

镜子不显示生命值，而采用三阶段视觉状态。

| 阶段    | 镜面变化      | 反馈强度       |
| ----- | --------- | ---------- |
| 第一次命中 | 命中点产生主裂纹  | 小型闪光、轻微震动  |
| 第二次命中 | 裂纹向镜面边缘扩散 | 掉落碎屑、倒影失真  |
| 第三次命中 | 镜面完全破裂    | 顿帧、震屏、碎片爆发 |

每次攻击产生的裂纹都应从实际命中位置出现，使玩家感到自己确实在主动破坏镜面。

裂纹不建议铺得过于密集。每个阶段可以增加两到三条主要裂纹，再通过少量细裂纹补充，保持像素画面的清晰度。

---

## 5. 镜面完全破碎

第三次有效攻击后，镜面进入最终破碎状态。

推荐演出顺序：

1. 攻击命中后短暂停顿；
2. 白色冲击点迅速扩大；
3. 裂纹瞬间覆盖主要区域；
4. 镜面分裂成大、中、小三种碎片；
5. 碎片停留约0.1—0.2秒；
6. 所有碎片反常地向镜框内部倒飞；
7. 镜框内部形成深色镜像入口；
8. 镜中Boss轮廓在入口深处短暂出现。

碎片应以较大的几何块为主，不需要模拟大量真实玻璃。少量高识别度碎片比高密度粒子更符合极简风格。

---

# 六、现实世界美术风格

现实世界代表稳定、沉寂和不完整。

## 视觉特征

* 画面以深灰、蓝灰和黑色为主；
* 建筑结构完整但缺少生气；
* 地面和平台形状规整；
* 背景运动缓慢；
* 光线方向稳定；
* 镜子是区域中最亮的对象。

现实世界不应过于破败，也不需要大量遗迹装饰。可以表现为一个被镜面力量冻结、抽离色彩的世界。

### 现实层推荐色板

| 用途   | 色值        |
| ---- | --------- |
| 远景   | `#10141C` |
| 中景   | `#1C2330` |
| 平台主体 | `#303846` |
| 平台边缘 | `#566172` |
| 环境弱光 | `#75859A` |
| 玩家主体 | `#EEF3F6` |

---

# 七、镜像世界美术风格

镜像世界不是现实场景简单翻转，而是现实世界被镜面重新解释后的空间。

## 视觉特征

* 平台与建筑结构存在局部对称；
* 部分环境碎片悬浮在空中；
* 地面出现镜面反射，但反射不完全同步；
* 远景产生横向或纵向错位；
* 场景边缘偶尔发生一像素至数像素的抖动；
* 镜面裂光沿着地面和平台边缘移动；
* 重力方向仍然正常，避免增加玩法实现成本。

镜像世界应比现实世界更亮，但不能更杂乱。亮度主要集中在：

* 平台边缘；
* 裂纹；
* Boss轮廓；
* 攻击特效；
* 空间中的漂浮碎片。

### 镜像层推荐色板

| 用途   | 色值        |
| ---- | --------- |
| 远景深色 | `#0B1020` |
| 中景蓝灰 | `#17253B` |
| 镜面区域 | `#253C58` |
| 裂光蓝  | `#59C8FF` |
| 冷白高光 | `#DDF7FF` |
| 异常紫光 | `#887AFF` |

现实层与镜像层应使用同一套基础资产，通过调色、材质、碎片和背景运动方式形成差异，从而控制制作成本。

---

# 八、敌人美术设计

普通敌人保持剪影化，不追求复杂服装和器官设计。

## 影卫

* 深灰色近战人形；
* 身体略微向前倾；
* 手臂或武器形成清晰尖锐轮廓；
* 攻击前身体边缘出现短暂白光；
* 被击败后化为较暗的镜片碎屑。

## 棱光射手

* 身体较窄；
* 头部或手臂存在明亮发射点；
* 弹道使用清晰直线或菱形光束；
* 远程攻击前出现稳定的瞄准线；
* 不使用大量粒子遮挡战场。

普通敌人的配色应低于玩家、Boss和镜子的亮度，避免抢夺视觉焦点。

---

# 九、战斗特效风格

特效采用**几何化、短生命周期和高对比轮廓**。

## 普通攻击

* 白色或浅蓝色弧形残影；
* 残影持续时间较短；
* 不绘制复杂火焰或能量纹理；
* 命中点采用十字闪光、线状裂光或小型镜片。

## 受击

* 短暂白色闪烁；
* 少量方形或三角形碎片；
* 极短顿帧；
* 受击方向清晰。

## 镜刃

* 使用细长、锋利的蓝白色几何形；
* 飞行过程中保留短残影；
* 命中后出现小范围镜面裂纹；
* 不做厚重的大型剑气。

## 回声冲刺

* 玩家本体保持清楚；
* 身后生成两至三个逐渐变暗的残影；
* 残影发生轻微水平错位；
* 起点和终点出现短暂镜面波纹。

---

# 十、动画风格

角色动画应强调动作轮廓，不强调细腻骨骼变化。

建议采用：

* 待机：4—6帧；
* 跑步：6—8帧；
* 跳跃：起跳、上升、下落、落地四个主要状态；
* 普攻：每段4—6个关键帧；
* 受击：2—4帧；
* 闪避或冲刺：短动作配合残影表现。

极简角色的动作幅度需要适当放大，例如：

* 攻击时肩部和手臂轮廓明显伸展；
* 起跳时身体快速压缩；
* 落地时腿部下沉；
* Boss动作使用更强的预备姿态。

不能依靠五官表达情绪，而应依靠身体倾斜、停顿和动作节奏表达。

---

# 十一、UI美术风格

UI延续极简镜面语言。

## 基础原则

* 以细线、矩形和裂纹为主；
* 不使用复杂装饰边框；
* 不遮挡角色附近区域；
* 使用白色、蓝灰色和少量冷蓝色；
* Boss相关UI可以加入黑色镜像版本。

## 具体表现

### 玩家生命值

使用简洁水平条，生命损失时条体像镜片一样逐段破裂。

### Boss生命值

Boss血条可以是一条完整镜面，受到伤害后不断出现裂纹。Boss死亡时整条血条破碎。

### 能力获得提示

新能力图标由镜片从四周汇聚形成，随后短暂发光。文字只保留能力名称和一个操作提示，不使用大段说明。

### 交互提示

镜子初次可攻击时，不直接显示“按键进入”，而可以显示：

> 攻击镜面

这样更符合玩家主动打碎镜子的设计。

---

# 十二、镜头与画面反馈

镜头整体保持稳定，避免频繁大幅移动。

只在关键节点强化：

* 普通攻击命中：极轻微镜头震动；
* 镜子第二阶段破裂：一次短震动；
* 镜面完全破碎：较明显震动和短暂画面停顿；
* Boss能力释放：轻微拉远或保持空间；
* Boss死亡：镜头暂时聚焦Boss与玩家之间。

后处理应谨慎使用：

* Bloom只作用于裂光、镜刃和能力节点；
* 色差只在进入镜像世界或强烈空间失真时短暂出现；
* 不长期启用强烈模糊；
* 不使用过高亮度覆盖像素轮廓。

---

# 十三、统一制作规范

## 必须保留

* 极简白色玩家；
* 黑色同形镜像；
* 纤细镜框；
* 灰蓝镜面；
* 分阶段裂纹；
* 大块几何碎片；
* 冷蓝色能力光；
* 现实与镜像层明显区分。

## 应当避免

* 复杂哥特雕花镜框；
* 大量尖刺、旗帜和祭坛；
* 过于写实的玻璃反射；
* 高密度环境纹理；
* 大面积绚丽魔法粒子；
* 多种高饱和颜色同时出现；
* 让镜子看起来像普通魔法传送门；
* 让特效完全遮住极简角色。

---

# 十四、美术资产制作优先级

## 第一阶段：核心可玩切片

优先完成：

1. 玩家基础动作；
2. 基础现实层平台；
3. 完整状态镜子；
4. 三阶段裂纹；
5. 镜面破碎动画；
6. 黑色镜像Boss；
7. 基础攻击和命中特效；
8. 简单镜像层背景。

这部分足以完成“现实推进—主动破镜—进入镜中—挑战Boss”的核心展示。

## 第二阶段：主题强化

继续增加：

* 镜中倒影错位；
* 镜片向内坍缩；
* Boss能力光效；
* 镜像层漂浮碎片；
* 能力吸收演出；
* 镜面风格UI。

## 第三阶段：整体润色

最后处理：

* 环境雾和微粒；
* 场景局部反射；
* 不同区域的背景变化；
* 镜头震动与顿帧；
* 调色和Bloom强度；
* Boss登场与死亡演出。

---

# 十五、美术概念总结

《镜中试炼》的美术核心不是制作一个华丽的魔法世界，而是利用极简画面建立强烈的视觉关系：

> **白色玩家面对黑色镜像，完整世界面对破碎镜面，稳定现实面对失真镜域。**

镜子始终是画面的视觉中心。它最开始安静地反射玩家，随后表现出不受玩家控制的倒影；玩家使用普通攻击主动制造裂纹，最终击碎镜面，进入由碎片、冷光和错位空间构成的镜像世界。

整体美术应形成“**低成本基础资源＋高完成度关键演出**”的制作结构，使有限的Demo体量仍然具有明确且统一的Mirror主题。
