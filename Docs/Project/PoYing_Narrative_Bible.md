# 《破映》叙事设计母稿

> 版本：v0.1（讨论稿）  
> 用途：作为后续标题、菜单、关卡、Boss、能力获得、演出、UI 文案与答辩表述的统一叙事依据。  
> 当前阶段：只确定故事与表达原则，不直接约束具体实现方案。

## 一、项目的一句话

> 你失去了记忆、能力与原本的模样。它们散落在破碎世界的倒影中。你需要穿过这些世界，击败镜中的自己，把自己一点点找回来。

更短的宣传表达：

> 在破碎中，找回自己。

答辩表达：

> 《破映》讲述了一个失去一切的人，在破碎世界中逐步找回自己的故事。每一个镜像 Boss 都持有主角失去的一部分；玩家通过战胜镜像夺回能力，并最终重新成为完整的自己。

## 二、标题含义

“破映”同时包含两层意思：

1. **破碎倒影**：玩家必须进入破碎世界，面对并击败镜中的另一个自己。
2. **打破映像**：玩家最终打破“倒影比自己更完整”的关系，不再由镜中的形象定义自己。

标题不是单纯描述“打碎镜子”，而是在概括整个角色弧光：主角最初只能从倒影中确认自己缺少什么，最后则能够独立、完整地站在镜子前。

正式标题建议：

```text
破映
在破碎中，找回自己
```

## 三、故事的核心命题

《破映》不是救世故事，也不是揭露阴谋的故事。

它只讲一件事：

> 一个什么都没有的人，走进破碎的倒影，把属于自己的部分带了回来。

故事的核心不是“变得更强”，而是“重新完整”。能力成长、外形变化和记忆恢复，都是这个过程在不同层面的表现。

玩家面对的也不是真正意义上的外部反派。镜像 Boss 是主角失去部分的载体。每一次战斗既是对抗，也是辨认、接受与收回。

## 四、世界规则

### 1. 世界曾经完整

世界原本由同一套现实维系。某次无法追溯的镜面破裂，使完整世界分裂成多个彼此不同的残片。

这次破裂的具体原因不作为当前故事重点。游戏不需要通过阴谋、组织或神明解释它。玩家只需要理解：世界已经破碎，而主角也在同一刻被破碎了。

### 2. 主角被镜子剥离

镜面破裂时，主角的三类事物被分别剥离：

| 被剥离的部分 | 在游戏中的表达 |
| --- | --- |
| 能力 | 被镜像 Boss 使用；击败 Boss 后成为玩家的新能力 |
| 记忆 | 以短暂画面、声音、动作印象或场景残响出现 |
| 模样 | 主角由白色无面形象逐步恢复轮廓、色彩或细节 |

三者共同说明“找回自己”。其中能力是主要玩法反馈，外形是持续视觉反馈，记忆是克制的叙事反馈。

### 3. 白色无面身体是“剩下的自己”

主角醒来时没有面孔、明确身份和过去，只剩下一具白色身体。

它不是替身、复制品或人工制造的容器，而是主角在一切被剥离之后仍然留下的“本体”。这使玩家从一开始就能理解：主角不是要成为镜中人，而是要把原本属于自己的东西取回来。

### 4. 破碎世界既是地点，也是倒影

每个关卡都是完整世界的一块残片，也对应主角被剥离的一部分。不同关卡可以拥有明显不同的美术风格，因为它们不是连续地理空间，而是由不同记忆和能力塑造出的镜面残片。

现实区域负责让玩家穿过残片、感受缺失；镜中区域负责让缺失的部分以 Boss 的形式站到玩家面前。

### 5. 镜像比主角更完整

每个镜像 Boss 都与主角相似，却比当前的主角多拥有一些东西：更清晰的形象、一种能力、一段记忆，或者更确定的行动方式。

因此玩家第一次看见镜像时，应该产生的不是“它在模仿我”，而是：

> 它拥有本该属于我的东西。

### 6. 击败不等于杀死

Boss 被击败后不是作为生命消亡，而是失去独立形态，碎成镜片、光或残响，重新回到主角身上。

这条规则决定了能力获得演出的含义：玩家不是抢走敌人的战利品，而是在完成一次重新整合。

### 7. 镜子不审判玩家

旧版本中的“试炼”“证明自己”“引路者”等表达会让镜子像一个有意志的考官，并自然引出幕后规则制定者。

《破映》不需要这层设定。镜子只是破裂发生的媒介和缺失部分的入口。它不会选中玩家，也不会要求玩家证明资格。玩家进入镜中，是因为那里有自己失去的东西。

## 五、主要叙事实体

### 主角

- 没有姓名，避免额外身份设定分散主题。
- 开场是白色、无面、缺少细节的形象。
- 原则上不与其他角色对话；游戏中的叙事文本统一采用主角的第一人称内心独白。
- 最初的行动动机不是拯救世界，而是来自最直接的认知：镜中的人拥有自己缺少的东西。
- 每取回一部分，动作、能力、外形或声音都会更完整。

### 镜像 Boss

- 外形与主角同源，但比主角更具体、更鲜明。
- 每个 Boss 只集中代表一种缺失，不承担复杂人物支线。
- Boss 的能力、战斗主题、场景表现和奖励必须保持一致。
- Boss 可以沉默，或只说极少量与“归还、取代、完整”有关的话。
- Boss 不应被写成邪恶人格。它们会反抗，是因为镜像已经把自己当成了完整的存在。

### 完整倒影

最终面对的不是统治镜域的王，也不是幕后黑手，而是“比主角更像主角”的完整倒影。

它拥有清晰形象、全部能力与剩余记忆，是主角一路以来对自身缺失的最终投射。最终战的意义不是击败世界的统治者，而是打破“只有倒影才是完整的我”这一关系。

### 叙事声音

取消独立的“引路者”角色，也不设置全知旁白。

游戏内所有叙事短句都来自主角本人。它们不是主角对玩家解释设定，也不是与其他角色交谈，而是主角在行动中产生的感觉、判断与逐渐恢复的记忆。

即使出现“记忆残响”，也应由主角用第一人称感知，例如“我来过这里”“我记得这个动作”，而不是由另一个声音告诉主角答案。

这样可以避免引出三个不必要的问题：引路者是谁、它为何帮助主角、它是否制造了这场试炼；同时让“找回自己”既是故事目标，也是玩家阅读文本时持续经历的主观过程。

### 第一人称叙事规则

第一人称只用于游戏内叙事，不要求项目简介、答辩稿和系统设置也使用第一人称。

游戏中的第一人称文本遵循以下原则：

- 只说主角此刻能够感知、判断或记起的内容。
- 不替世界下全知结论，不提前解释镜面为何破裂。
- 用日常、直接的话，不写成诗、谜语或文学旁白。
- 能不说就不说；不要为了配合每个操作而强行安排一句内心独白。
- 从迟疑、陌生逐渐过渡到确定、主动。
- 不单独显示“主角”“旁白”“镜中低语”等说话者标签。
- 操作按键、设置选项等纯系统信息可以保持客观，不必强行写成内心独白。

主角的语言变化应对应角色成长：

| 阶段 | 语言状态 | 示例 |
| --- | --- | --- |
| 开场 | 困惑、短促、只能描述眼前 | “我是谁？” |
| 第一次看见倒影 | 不确定镜中人与自己的关系 | “镜子里的……是我吗？” |
| 第一次取回 | 确认能力属于自己 | “我会用这个。” |
| 中段 | 知道自己还没有找完 | “还有东西没拿回来。” |
| 最终战前 | 不再跟随倒影 | “这次，我不会跟着你走了。” |
| 结局 | 确认自己已经完整 | “我都拿回来了。” |

## 六、主角的成长结构

主角的成长分为三个同步但权重不同的层面：

### 1. 玩法层：能力回来

这是最明确的成长。Boss 先使用能力压迫玩家，玩家在战斗中理解能力，击败 Boss 后获得玩家版本，并在后续关卡中使用它。

```text
看见缺失
→ 被缺失压迫
→ 学会面对它
→ 将它取回
→ 用取回的部分继续前进
```

### 2. 视觉层：模样回来

主角不应直到结局才突然从白色无面变成完整形象。每次取回应留下一个小而可见的变化，例如：

- 身体出现一种稳定色彩；
- 面部或发型恢复一部分轮廓；
- 武器由虚影变为实体；
- 待机姿态从茫然变得确定；
- 镜中倒影与本体的差距逐步缩小。

具体恢复哪些部位需要结合现有角色资源另行决定，但原则是“持续可见，不必复杂”。

### 3. 情绪层：选择回来

开场时，主角只是在追随倒影留下的线索。随着能力和记忆恢复，玩家越来越主动地进入下一块残片。

最终成长不是“终于知道别人要我做什么”，而是“即使镜中仍有另一个自己，我也知道该如何行动”。

## 七、完整故事流程

### 序章：空白之人

主角在破碎空间中醒来，只剩白色无面的身体。四周没有解释，只有一面仍然完整的主镜。

镜中站着一个与主角动作相似、却拥有完整形象的人。它没有攻击，只向后退一步，让出镜后的裂隙。

主角看见镜中的完整形象：

> 镜子里的……是我吗？

当倒影退入镜隙后：

> 我得进去看看。

主角踏入镜隙。

这一段需要让玩家立即理解三个事实：我是不完整的；镜中的我更完整；我要进入镜子。

### 第一段：第一次取回

玩家进入第一块世界残片。这里承担基础移动、攻击与生存教学，但不再被包装成“试炼”。

基础操作不需要逐项配内心独白。直接显示清楚的系统提示：

```text
移动    A / D
跳跃    空格
攻击    J / 鼠标左键
闪避    左 Shift
```

如果这一段确实需要一句话交代主角的行动，只使用自然、直接的表达：

> 我得先离开这里。

不为“学会移动”“学会跳跃”分别编写文学化句子。操作教学属于系统信息，不需要伪装成剧情。

关卡尽头，玩家见到第一个镜像 Boss。它比主角拥有更完整的战斗姿态，并使用主角尚未拥有的能力。

击败后，Boss 破碎并回归主角。玩家获得第一项能力，同时恢复第一处可见的形象细节和一个极短的记忆残响。

这里完成第一次叙事证明：镜中人拥有的，确实可以被取回。

### 第二段：学会使用取回的自己

玩家进入风格明显不同的第二块世界残片。此前获得的能力在这里不只是可选攻击，而是能够明显改善推进、战斗或机关处理。

玩家随后面对第二个镜像 Boss。它代表另一种缺失，并迫使玩家同时使用基础动作与第一项取回能力。

击败后，玩家获得第二项能力，恢复更多外形和记忆。此时主角与镜像之间的外观差距已经缩小，但仍能看出主角缺少最后一部分。

### 尾声：回到最初的镜子

取回主要能力后，主角回到最初醒来的地方。

主镜仍在，镜中的人也仍在。但这一次，倒影不再后退让路，而是使用玩家已经见过和掌握的全部能力迎战。

最终战不是加入一套完全陌生的规则，而是综合检验玩家已经取回的部分。玩家是在用重新成为自己的过程，对抗那个曾经看起来比自己更完整的形象。

### 结局：不再有更完整的倒影

完整倒影被击败后，镜面破裂。剩余记忆与形象回到主角身上。

主镜随后短暂恢复。主角再次站到镜前。

开场时，镜中的人比主角完整；结尾时，镜中与镜外终于一致。倒影不再领先、不再引路，也不再拥有主角所没有的东西。

主角转身离开。倒影在同一刻转身。

最后一句可以是：

> 我都拿回来了。

随后回到标题：

```text
破映
在破碎中，找回自己
```

## 八、Boss 与能力的叙事对应

以下为当前推荐结构，名称仍可继续讨论：

| 阶段 | 镜像 | 它持有的部分 | 战斗主题 | 玩家取回的内容 |
| --- | --- | --- | --- | --- |
| 第一镜 | 刃镜 | 主动出手与远程反击的能力 | 读招、闪避、抓破绽 | 镜刃 + 第一处外形细节 + 动作记忆 |
| 第二镜 | 回声 | 穿过危险、改变位置的能力 | 空间判断、残影、位移压力 | 回声冲刺 + 第二处外形细节 + 路径记忆 |
| 最终镜 | 完整倒影 | 剩余形象与记忆 | 已有能力的组合考验 | 完整形象与自我确认 |

这里应避免把能力强行解释成人格标签。例如“镜刃等于攻击性”“冲刺等于逃避”容易让故事显得刻意。能力首先是主角真实失去的身体与战斗能力，情绪含义只通过体验自然产生。

## 九、叙事语气与文本原则

### 应该保持

- 简短，通常一句话只表达一个意思。
- 游戏内叙事统一采用主角的第一人称内心独白。
- 克制，不主动解释镜面破裂的全部历史。
- 口语化，像角色真的会在当下想到的话。
- 能用画面和动作讲清楚的内容，不再补一句台词。
- 留白，让场景变化和能力获得承担主要叙事。
- 从冷清、陌生逐步走向确定、完整。

### 应该避免

- “伟大的使命”“拯救世界”“命定之人”。
- “通过试炼才有资格”的考核式表达。
- 突然出现的组织、神明、镜域统治者或幕后阴谋。
- 大段旁白解释世界观。
- 把普通操作写成诗意的身体感受。
- “双脚仍然记得”“身体没有忘记”一类刻意的文学表达。
- 把 Boss 写成与主角无关的守关怪物。
- 每获得能力都用系统语言直接说“技能已解锁”，却没有叙事反馈。

### 推荐词汇

```text
破碎、残片、倒影、镜隙、失去、留下、取回、记起、归还、完整
```

### 谨慎使用或淘汰的词汇

```text
试炼、资格、选中、引路者、镜域之主、救世、封印、使命
```

## 十一、当前版本与新叙事的关系

现有游戏结构可以继续使用：

```text
现实区域推进
→ 镜门／镜隙
→ 镜像 Boss
→ 能力获得
→ 返回现实区域
→ 使用新能力继续前进
→ 最终综合战
```

需要改变的是这套结构的叙事解释：

| 旧解释 | 《破映》的解释 |
| --- | --- |
| 玩家参加镜界试炼 | 玩家进入残片寻找失去的自己 |
| 镜子要求玩家证明资格 | 镜子是通往缺失部分的入口 |
| 引路者指导玩家 | 主角以第一人称察觉身体仍记得的事 |
| Boss 是守关者或镜域敌人 | Boss 是获得独立形态的自我残片 |
| 击败 Boss 获得奖励技能 | 击败镜像后取回原本属于自己的能力 |
| 最终击败镜域之主 | 最终打破比本体更完整的倒影 |

## 十二、需要共同确认的问题

### 1. 主角最终是否露出明确面孔

当前推荐：**恢复完整形象，但不必给出写实、具体的面部特写。**

原因是“完整”需要视觉兑现，但过于具体的脸可能削弱玩家代入。可以通过色彩、轮廓、服装、头发与眼部微光说明主角已经完整。

### 2. 记忆是否要讲述具体过去

当前推荐：**只恢复感官与动作记忆，不展开具体人物关系。**

例如手握武器的触感、曾走过的道路、镜子破裂前的一瞬，而不是父母、王国、恋人或完整身世。这样能保持故事小而集中。

### 3. 镜面为何破裂

当前推荐：**不在主线中解释。**

它可以作为世界已经发生的事实。若答辩需要，可表述为“镜面破裂导致世界与主角同时碎片化”，不继续追问制造者和目的。

### 4. 镜像是否说话

当前推荐：**所有镜像保持沉默，包括最终倒影。**

镜像通过与玩家相似的动作、迟半拍或快半拍的模仿、以及能力展示来表达身份。所有文字都保留在主角的第一人称视角中，避免镜像变成会解释世界观的独立反派。

### 5. 最终结局是“恢复原样”还是“成为新的自己”

当前推荐：**主角取回全部失去之物，但最终形象不是被倒影直接覆盖，而是在本体上完成重组。**

这样既兑现“把原本的自己带回来”，也保留“打破映像、不被倒影定义”的第二层含义。

## 十三、后续工作顺序

这份母稿确认后，再按以下顺序落到具体体验：

1. 确认主角、两名阶段 Boss 与最终倒影的叙事定位。
2. 确认每次取回时的能力、外形变化与记忆残响。
3. 编写完整的开场、关卡节点、Boss 前后与结局文本表。
4. 对照现有关卡，确定哪些叙事通过场景、动画、UI 或短句表达。
5. 最后统一修改标题界面、教程、Boss 名称、能力获得和结局体验。
