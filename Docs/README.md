# Mirror Trial Docs

This folder stores project documents only. Runtime Unity assets, scripts, prefabs, configs, and materials should live under `Assets/MirrorTrial`.

## Folder Rules

| Folder | Purpose |
| - | - |
| `Design` | Game design docs, 3C docs, combat design, player design, boss design, system design. |
| `Planning` | Implementation plans, AI handoff notes, task breakdowns, milestone plans. |
| `Diagrams` | SVG diagrams, exported flow images, generated visual references. |
