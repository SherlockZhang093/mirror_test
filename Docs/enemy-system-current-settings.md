# 敌兵系统当前设置说明

> 更新日期：2026-07-28  
> 本文记录当前项目中普通关卡敌兵的实际配置与运行方式。镜中 Boss 不使用这套逻辑。

## 1. 敌兵的制作与放置入口

### 敌人编辑器

菜单：`Tools > 镜像试炼 > 关卡 > 敌人编辑器`

这里负责：

- 输入敌兵编号和名称，生成敌兵资源。
- 编辑敌兵 Prefab 自身的生命、移动、攻击、受击、碰撞框和攻击特效。
- 每个敌兵 Prefab 自动绑定一份专属 AI 配置，不需要在关卡编辑器里再次选择 AI。

生成目录：

```text
Assets/MirrorTrial/Enemies/{敌兵编号}_{敌兵名称}/
├─ Sprites/       图片
├─ Animations/    动画与 Animator Controller
├─ AIProfiles/    该敌兵专属 AI 配置
└─ Prefabs/       敌兵 Prefab
```

新建敌兵时会自动生成 `SpriteRenderer`、矩形碰撞框、`Hurtbox`、`Rigidbody2D`、`EnemyAI` 和 `AttackEffectPoint`。初始方块图片只是占位，之后可换成正式美术资源。

### 关卡编辑器的敌兵页面

这里仅负责关卡内每只敌兵的：

- 放置位置。
- 探测矩形的宽和高。
- 向左、向右巡逻的距离。

选中层级中的敌兵后：

- 黄色矩形：探测范围，可直接在 Scene 中拖动四边。
- 绿色左右端点：巡逻边界，可分别拖动。
- 每个关卡实例都可以拥有不同的探测范围和巡逻边界。

关卡编辑器不负责选择 AI、配置攻击、生命值、移动速度、碰撞框或特效；这些内容属于敌兵 Prefab。

## 2. 当前敌兵运行逻辑

1. 敌兵出生后，以关卡中的放置位置作为巡逻中心。
2. 未发现玩家时，在绿色左右边界之间来回巡逻。
3. 到达巡逻端点后，等待“巡逻端点等待时间”，再转身继续移动。
4. 玩家进入以敌兵当前位置为中心的黄色探测矩形后，敌兵追向玩家。
5. 玩家与敌兵的直线距离小于等于“开始攻击距离”，且攻击冷却结束时，敌兵开始攻击。
6. 到达“伤害帧延迟”时执行近战判定或生成远程子弹，同时生成攻击特效。
7. 玩家离开当前探测矩形后，敌兵停止追击或取消尚未完成的攻击，并返回巡逻状态。

注意：黄色探测矩形会跟随敌兵移动，并不是固定在地图上的警戒区。绿色巡逻边界以运行开始时的出生位置为基准。

## 3. 敌兵 Prefab 设置

### 敌兵基础配置

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 专属 AI 配置 | 自动绑定 | 当前 Prefab 独占的 AI 配置，只读显示 |
| 单独生命值 | -1 | `-1` 使用专属 AI 配置；其他值只覆盖这一只 Prefab 的生命值 |
| 单独移动速度 | -1 | `-1` 使用专属 AI 配置；其他值只覆盖这一只 Prefab 的移动速度 |

### 基础属性

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 最大生命值 | 2 | 敌兵能承受的总伤害 |
| 移动速度 | 2.5 | 巡逻和追击时的水平速度 |
| 移动时自动转向 | 开启 | 根据移动方向左右翻转敌兵图片 |

### 探测、巡逻与追击

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 默认探测距离 | 8 | 关卡实例没有单独设置矩形时，生成宽高各为 `16` 的默认探测矩形 |
| 开始攻击距离 | 1.2 | 玩家离敌兵多近时，敌兵停止追击并进入攻击状态 |
| 巡逻端点等待时间 | 1 秒 | 敌兵到达左端或右端后停留多久 |

“开始攻击距离”和“攻击判定距离”不是同一个设置：

- 开始攻击距离决定敌兵何时开始播放攻击。
- 攻击判定距离决定攻击真正能打到多远。
- 若开始攻击距离明显大于攻击判定距离，敌兵可能站得太远而挥空。
- 近战敌兵通常建议先让二者接近，再按动画手臂或武器长度微调。

### 攻击

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 攻击前摇 | 0.35 秒 | 一次攻击状态持续的时间 |
| 攻击冷却 | 1.2 秒 | 一次攻击结束后，下一次攻击前至少等待多久 |
| 攻击判定距离 | 1.2 | 近战判定矩形的水平宽度；判定高度当前固定为 `0.8` |
| 攻击伤害 | 1 | 命中玩家时造成的伤害 |
| 伤害帧延迟 | 0.1 秒 | 进入攻击状态后，等待多久才真正执行伤害、生成子弹和攻击特效 |
| 远程子弹预制体 | 空 | 留空为近战；指定后自动成为远程敌兵 |
| 子弹生成偏移 | (0.4, 0.2) | 子弹相对敌兵中心的水平和垂直生成位置 |
| 攻击时停止移动 | 开启 | 攻击期间将水平速度清零 |

近战判定始终生成在敌兵面向的一侧。远程子弹速度当前为敌兵移动速度的 2 倍；使用项目的 `MirrorBladeProjectile` 时，最大飞行距离当前固定为 8。

代码中还保存了攻击打断力、韧性伤害、玩家受击类型和破霸体开关，但目前敌兵自定义面板未显示这些高级参数。

### 受击与死亡

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 受击硬直时间 | 0.25 秒 | 普通受击状态和 `Attacked` 动画至少保持多久 |
| 受击后退力度 | 4 | 敌兵被攻击时，使用攻击数据中的击退向量产生物理后退 |
| 死亡销毁延迟 | 0.3 秒 | 仅在敌兵没有图片组件时使用 |
| 死亡闪烁次数 | 2 | 死亡后销毁前闪烁几次 |
| 死亡闪烁间隔 | 0.08 秒 | 每次隐藏或显示保持的时间 |

普通致命攻击会先进入受击状态并播放 `Attacked`，硬直结束后再死亡。击飞致命攻击会等击飞和落地流程结束后再死亡。

### 击飞表现

这组设置只控制被技能击飞后的动画和视觉表现，不改变技能传入的击飞力度。

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 起飞动画状态 | HitDamage | 刚被击飞时播放的 Animator 状态名 |
| 空中动画状态 | 空 | 敌兵上升或停留在空中时的状态名 |
| 下落动画状态 | 空 | 敌兵开始下降时的状态名 |
| 落地动画状态 | 空 | 落地时的状态名 |
| 落地恢复时间 | 0.18 秒 | 落地后多久恢复普通 AI |
| 地面检测距离 | 0.08 | 用于判断是否落地 |
| 显示击飞特效 | 开启 | 是否显示起飞、空中拖尾和落地效果 |
| 起飞爆点大小 | 1.65 | 起飞瞬间效果大小 |
| 空中拖尾大小 | 1.1 | 空中拖尾效果大小 |
| 落地冲击大小 | 1.55 | 落地效果大小 |

动画状态留空时，该阶段不会强制切换动画。

### 移动限制

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 悬崖检测距离 | 0.5 | 向前下方检测地面的距离；设为 0 可关闭 |
| 墙壁检测距离 | 0.3 | 向前检测墙壁的距离；设为 0 可关闭 |
| 遇到悬崖时转身 | 开启 | 巡逻或追击遇到悬崖边缘时转身；关闭时会停住 |

墙壁和地面检测使用 `Ground` Layer。关卡地形若未放在该 Layer，敌兵无法正确识别墙壁与悬崖。

### 碰撞框

| 设置 | 作用 |
|---|---|
| 中心偏移 | 调整矩形碰撞框相对敌兵根节点的位置 |
| 宽 / 高 | 调整敌兵身体矩形碰撞框大小，最小为 0.01 |

### 攻击特效

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 攻击特效预制体 | 空 | 伤害帧到达时生成的小特效 |
| 武器或手部挂点 | 自动创建 | 特效生成位置，建议移动到武器或手部 |
| 特效保留时间 | 1 秒 | 生成后多久自动销毁 |
| 根据朝向翻转特效 | 开启 | 敌兵朝左时自动水平翻转特效 |

若挂点为空，可点击“创建攻击特效挂点”。挂点是敌兵的子物体，可以直接修改其 Transform 来微调位置。

## 4. 关卡内每只敌兵的独立设置

| 设置 | 作用 |
|---|---|
| Transform | 决定敌兵在关卡里的出生位置 |
| 探测矩形 宽 / 高 | 决定这一只敌兵能在多宽、多高的区域内发现玩家 |
| 向左巡逻距离 | 从出生位置向左最多巡逻多远 |
| 向右巡逻距离 | 从出生位置向右最多巡逻多远 |

这些值保存在关卡场景中的敌兵实例上，不会修改原始 Prefab，也不会影响其他关卡里的同类敌兵。

## 5. 动画接入要求

敌兵动画驱动需要敌兵对象上同时存在 `Animator` 和 `EnemyAIAnimator`。Animator Controller 中使用以下状态名：

| 状态名 | 何时播放 |
|---|---|
| Walk | 巡逻和追击 |
| Attack | 进入攻击状态 |
| Attacked | 普通受击或致命受击的硬直阶段 |

使用的 Animator 参数：

| 参数 | 类型 | 作用 |
|---|---|---|
| IsMoving | Bool | 当前是否处于巡逻或追击 |
| Attack | Trigger | 进入攻击状态时触发 |

当前没有单独的站立动画状态：敌兵会持续巡逻，只有到达端点等待、攻击、受击、击飞或死亡时暂时停止。左右行走通常使用同一份 `Walk` 动画，由 `SpriteRenderer.flipX` 自动翻转。

生成敌兵 Prefab 时不会自动创建 Animator Controller，也不会自动添加正式动画。把动画放进该编号的 `Animations` 文件夹后，需要给 Prefab 添加或配置 `Animator`、绑定 Controller，并确认有 `EnemyAIAnimator`。

## 6. 推荐调试顺序

1. 在敌人编辑器中先调整生命值、速度、攻击前摇、伤害帧延迟和攻击冷却。
2. 用攻击动画中武器真正接触玩家的时刻校准“伤害帧延迟”。
3. 用武器实际长度校准“攻击判定距离”。
4. 让“开始攻击距离”略小于或接近可靠命中的距离。
5. 在关卡编辑器里逐只拖动黄色探测矩形和绿色巡逻边界。
6. 进入 Play Mode 检查墙边、悬崖、不同高度平台、脱离探测区域和连续攻击。

## 7. 当前已知限制

- 没有波次生成逻辑；普通敌兵直接放在关卡场景中，运行时直接启用。
- 探测区域只有矩形形状，并始终跟随敌兵当前位置。
- 脱战没有额外的独立范围；玩家离开探测矩形即脱战。
- 近战判定高度固定为 0.8，目前不能在编辑器中单独修改。
- 远程弹道速度和项目子弹的最大距离目前没有独立面板设置。
- 敌兵生成工具不会自动制作 Animator Controller 或导入动画图片。
- 玩家被敌兵命中后的固定位置移动主要由玩家受击配置控制，不应只通过敌兵的“受击后退力度”来微调玩家位移。
